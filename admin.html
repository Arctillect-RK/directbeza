Как пополнять каталог

Сайт — статика на хостинге. Инструмент pars (SEO-комбайн) — отдельно, на вашем ПК: им собираете XLS, а на сайт только выкладываете карточку каталога. Файлы РК клиенту отдаёте вручную после оплаты (почта / Telegram / облако).

1. Собрать пакет (pars, локально)

  1. Откройте папку pars, запустите комбайн.
  2. Соберите фразы, заголовки, минуса.
  3. Вкладка «Директ XLS» → скачайте файл кампании.
  4. Файл храните у себя (не обязательно заливать на сайт).

2. Добавить карточку на сайт

Отредактируйте файл data/campaigns.json на хостинге (FTP / файловый менеджер):

{
  "id": 6,
  "title": "Название для клиента",
  "sphere": "Сфера / ниша",
  "description": "Кратко, что внутри пакета",
  "price": 9900,
  "preview": "img/campaigns/my-preview.jpg",
  "active": true,
  "created_at": "2026-07-22"
}
  • id — уникальный номер
  • preview — путь к картинке (загрузите JPG/PNG в img/campaigns/)
  • active": false — скрыть из каталога

3. Курс (3 500 ₽)

  • Уроки: data/private/course.json (закрыто от URL) · лендинг: data/course.json
  • Картинки: img/course/
  • Кабинет: learn.php + course-api.php (урок по одному, cookie)
  • Оплата ЮKassa: product_type=course, цена 3 500 ₽
  • Доступы: data/private/course-access.json
  • Инструкция: data/COURSE-EDIT.md

4. Заявки и оплата

В js/config.js:

  • LEADS_EMAIL / LEADS_EMAIL_CC — zakaz@ и info@ (FormSubmit)
  • TELEGRAM_USER — ник без @
  • PAYMENT_ENABLED — кнопка «Оплатить картой»

ЮKassa: buy.php, webhook.php, ключи в includes/yookassa-config.php. Webhook URL: https://directbeza.ru/webhook.php. Лог: data/payments.json.

После оплаты отправляете xlsx клиенту на email.

5. Что заливать на хост

Папка сайта directbeza.ru:

  • HTML + buy.php, webhook.php, success.php
  • includes/, css/, js/, img/, data/, favicon

Не нужно: Node, server.js, package.json, папка pars.
